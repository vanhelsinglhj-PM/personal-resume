01 / CONTEXT

项目背景Background

移动端核心 AIGC 功能（VEO3、图生视频等）生成成功率长期维持在 50% 左右，影响用户体验及留存，进而导致双端退款率偏高。Core mobile AIGC features such as VEO3 and image-to-video had long maintained a generation success rate of about 50%, hurting experience and retention while contributing to high refund rates on both platforms.

02 / CHALLENGE

问题与挑战Challenges

通过拉取错误码数据发现网络或系统错误在所有失败次数统计中占比45.57%，但中间层和AI云并未反馈具体原因，无法定位问题根源。Error-code analysis showed network or system errors represented 45.57% of all failures, but neither middleware nor the AI cloud reported a specific cause, preventing root-cause diagnosis.

03 / APPROACH

优化思路Approach
与解决方案and solutions

01

拉通客户端、中间层、AI云分析用户使用链路中的流程，定位核心问题：APP切换到后台满足一定时长后，系统会自动释放掉一些网络连接、后台任务资源，导致中间层在轮询云端任务时出现网络错误从而失败；Aligned client, middleware and AI cloud teams to trace the user journey. After the app stayed in the background for a period, the OS released network connections and background resources, causing errors while middleware polled cloud tasks.

02

优化 token 有效期至 7 天，用户退后台后返回 APP，未完成的云端任务可手动重试恢复；Extended token validity to seven days so unfinished cloud tasks could be manually retried when users returned to the app.

03

优化云端任务推送机制，若任务已生成，无论 APP 是否在后台，均在本地推送占位，同时中间层自动轮询任务结果，确保用户及时获取生成进度。Improved cloud task notifications: once a result is generated, create a local notification placeholder whether the app is foregrounded or backgrounded, while middleware polls the result to provide timely progress.

04 / OUTCOME

项目成果Outcomes

↑66.40%生成成功率Generation success rate
↓20.45%安卓退款率Android refund rate
↓12.83%iOS 退款率iOS refund rate

主要AIGC功能生成成功率平均提升66.40%（49.23%→81.92%），双端退款率分别降低20.45%和12.83%。Average generation success across major AIGC features rose 66.40% (49.23%→81.92%); refund rates on the two platforms fell 20.45% and 12.83%, respectively.
